# Operator user guide

The canonical guide is packaged with the application:
[Operator user guide](../../frontend/mission-planner/public/operator-help/guide.html).
Open **Operator → Help → User guide** on the running installation, or serve the
packaged HTML and its relative images locally. It requires no external
Markdown compiler or documentation service.

The HTML contains stable section anchors used by the private T01–T11 curriculum.
Update that canonical content and its checked screenshots; do not maintain a
second prose copy here. Human first-use and complete parity/course acceptance
remain recorded in the issue 376 implementation ledger and reports.
