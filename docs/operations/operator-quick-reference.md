# Operator quick reference

The canonical print reference is
[Operator quick reference](../../frontend/mission-planner/public/operator-help/quick-reference.html).
Open **Operator → Help → Quick reference**, then **Open for printing**. Use the
browser's Print command. The packaged HTML includes its own responsive and A4
print styles and links to the full local guide. Keep prose in that HTML so the
printed and in-application versions agree.
